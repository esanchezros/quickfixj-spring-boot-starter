= Project documentation

The link:../README.adoc[root README] provides the shortest path to a working Acceptor or Initiator.
Use the focused guides below for complete setup and maintenance information.

== User guides

* link:getting-started.adoc[Getting started] -- dependency selection, connector roles, and first application setup.
* link:configuration.adoc[Configuration reference] -- settings sources, properties, concurrency, dynamic sessions, placeholders, and inline settings.
* link:customization.adoc[Customization] -- application callbacks, bean overrides, and `QuickFixJTemplate`.
* link:operations.adoc[Operations and Actuator] -- endpoints, health indicators, JMX, and operational security.
* link:migration.adoc[Migration] -- version changes, multiple connectors, upgrade checks, and rollback guidance.
* link:examples.adoc[Examples] -- runnable applications organized by use case.
* link:compatibility.adoc[Compatibility] -- supported starter, Spring Boot, Java, and QuickFIX/J lines.
* link:support-policy.adoc[Support policy] -- maintenance scope for active, maintenance, and end-of-life branches.

QuickFIX/J owns the session-settings format and engine-level behavior.
Use the upstream https://quickfixj.org/docs/configuration[QuickFIX/J configuration guide] for schedules, persistence, validation, networking, proxies, and SSL.
